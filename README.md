# Sahel Agri Predictor V1 (TabPFN-3.5)

Binary **Cropland** prediction from tabular satellite + climate features, with **TabPFN-3.5** at the core,
a **CatBoost/LightGBM baseline** on the same split, and an agent that **predicts + explains + recommends** (FR/EN),
behind a small Streamlit demo. Scope: `docs/CDC.md` + `docs/ARCHITECTURE.md` only.

## 5-min setup

```bash
# 1. Clone + enter
cd priorlabs-hackathon-3.5

# 2. Virtualenv + deps (≈3 min)
virtualenv .venv && .venv/bin/pip install -r requirements.txt
# (Debian/Ubuntu alternative if virtualenv missing: sudo apt install python3.11-venv, then python3 -m venv .venv)

# 3. Key (TabPFN-3.5 API; local `tabpfn` fallback if unset)
export TABPFN_API_KEY="your-key-here"

# 4. Evaluate (trains TabPFN-3.5 + baseline, writes metrics)
.venv/bin/python scripts/evaluate.py

# 5. Demo
.venv/bin/streamlit run app/streamlit_app.py
```

Individual training scripts:

```bash
.venv/bin/python scripts/train_tabpfn.py
.venv/bin/python scripts/baseline.py
```

## Layout

```
src/data_loader.py   # parquet load + stratified 80/20 split seed 42
src/tabpfn_model.py  # TabPFNClassifier via tabpfn_client (TABPFN_API_KEY) + local tabpfn fallback
src/baseline.py      # CatBoost preferred, LightGBM fallback
src/agent.py         # predict + explain (top features) + recommend (FR/EN)
app/streamlit_app.py # upload CSV or sample, predict, explain
scripts/train_tabpfn.py | scripts/baseline.py | scripts/evaluate.py -> data/processed/metrics.json
```
